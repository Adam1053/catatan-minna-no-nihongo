# 📘 Minna no Nihongo 1 — Kumpulan Catatan

Kumpulan catatan lengkap **Minna no Nihongo 1 (みんなの日本語 初級Ⅰ)** dalam bentuk
HTML statis — kosa kata, pola kalimat, contoh, percakapan, dan tata bahasa untuk
setiap bab.

Furigana dapat disembunyikan untuk latihan. Semua file **offline-friendly** dan
**tanpa dependensi eksternal**.

---

## ✨ Fitur

- 📖 **Lengkap per bab** — Kosa Kata, Pola Kalimat, Contoh, Percakapan, Tata Bahasa
- 🈳 **Furigana toggle** — sembunyikan/tampilkan furigana untuk latihan mandiri
- 🎨 **Warna aksen per bab** — tiap bab punya warna khas sendiri (spektrum hue konsisten)
- 🃏 **Index interaktif** — kartu bab dengan warna match dengan tema babnya
- 🔍 **Cari & filter** — cari bab/tema, filter kategori, shortcut `/` untuk fokus search
- 📱 **Responsif** — nyaman dibaca di HP, tablet, dan desktop
- ♿ **Aksesibel** — `scope` pada tabel, `aria-pressed` pada toggle, skip-link
- 🚫 **Zero dependency** — buka file HTML langsung di browser, tidak butuh internet
- 🖨️ **Print-friendly** — layout rapi saat dicetak
