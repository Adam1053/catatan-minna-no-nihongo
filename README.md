## 📖 Tentang Proyek

Kumpulan catatan lengkap untuk buku **Minna no Nihongo 1 (みんなの日本語 初級Ⅰ)** — terdiri dari **25 bab**, masing-masing disajikan dalam satu file HTML mandiri yang bisa dibuka langsung di browser tanpa server, tanpa internet, dan tanpa install apa pun.

Setiap bab mencakup **5 komponen utama** yang dibutuhkan untuk belajar:
**Kosa Kata** · **Pola Kalimat** · **Contoh Kalimat** · **Percakapan** · **Tata Bahasa**.

## 🚀 Cara Pakai

### 💻 Buka Langsung (Offline)

1. **Clone** atau **download** repo ini sebagai ZIP
2. **Ekstrak** ke folder apa saja
3. **Double-click** file `index.html`
4. Pilih bab yang ingin dipelajari — **selesai!**

> ✅ Tidak perlu install apa pun. Tidak butuh koneksi internet. Bisa dijalankan dari USB flash drive sekalipun.
